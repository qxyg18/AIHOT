# 使用规则

本站为个人自用的信息聚合工具，只在本机运行（127.0.0.1），不对外提供服务，不公开分发作何内容。

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 2026-09-29 |
| 使用范围 | 仅本人本机，不对外 |
| 联系方式 | 无 |

页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。仅作个人阅读参考。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请回原文核对。原文版权归各来源所有；站内只展示摘要和原文链接，不展示全文。

## 2. 来源方的更正与下架

如来源方希望更正或调整展示方式，收到通知后立即处理。

## 3. 用途限制

仅供本人内部参考，不对外转载、不再分发、不用于任何对外发布的商业内容。所有经营判断以官方原文与原始数据为准。

## 4. 抓取与频率

信源按各自设定的间隔抓取，未设置高频轮询；发生抓取失败时不重试猛打，让失败源在后台标红后人工处理。

## 5. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。
