# 隐私说明

本站是个人自用工具，只在本机运行（127.0.0.1），没有其他用户，也不对外提供服务。

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 2026-09-29 |
| 运营主体 | 个人自用，非公开服务 |
| 隐私事务联系 | 无 |

页首说明：

> 本站不对外提供服务，只处理让网站正常运行所必需的信息。

## 1. 浏览器本地数据

收藏、已读记录和主题偏好只保存在本机浏览器里，不会发送到任何外部服务。清除浏览器数据后它们会消失。可以在“收藏”页导出和导入这些数据。

## 2. 数据落在哪里

内容存在本机的 PostgreSQL 容器里，随 Docker 卷一起留在本机磁盘上；不配置云备份，不上传任何第三方。抓取到的内容只保留摘要与原文链接，不保存原文全文。

## 3. 对外请求

本站运行时会向配置的信源站点发出抓取请求，并把待处理的资料发给所配置的大模型接口（OpenAI 兼容）。这些请求会带上信源地址与文章内容，不会带任何个人身份信息。模型接口的调用额度有预算上限。

## 4. 第三方内容

本站展示的是第三方原文的摘要与链接。点击原文链接后，你访问的是对方网站，适用对方的隐私政策。

## 5. 删除方式

删除本机的容器数据卷即可清空全部内容，不涉及任何远端副本。
