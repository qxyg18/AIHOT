
【标题自洽规则 — 让读者不点开就知道“这是关于谁的什么事”】

1. 标题必须点出核心主体：品牌名 / 公司名 / 产品线名 / 商场或平台名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。原标题带公司简称前缀（如“森马服饰:”）时去掉前缀。
3. 原标题只是代号 / 没信息量的 teaser（如“重磅上新”、“官宣”、“Day 1”、“新品来了”）时，结合【来源】和正文把主体补进标题。例：原标题“官宣 | 新品发布” + 来源“巴拉巴拉” → “巴拉巴拉发布新一季系列”。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体品牌时，用上位词（如“某童装品牌”）兜底，绝不凭“行业常识”编一个具体品牌名 / 产品线 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的品牌或一份已有数据，就改写成“发布 / 推出 / 上线 / 开业”。只有原标题明确宣布了发布、推出、开业或融资，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的品牌、公司、渠道名。
   例：原标题“How Balabala runs its franchise network” → “巴拉巴拉如何运营加盟网络”，不能写成“巴拉巴拉开放加盟”。
   例：原标题“How to run a kids-wear store profitably” + 来源和正文明确是某品牌加盟体系 → “儿童服装门店如何做出利润”，不能只写成缺主体的“如何把门店做赚钱”。
